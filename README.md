# JoyLab Search Engine

A search and AI citation optimization engine for JoyLab covering SEO, AEO, GEO, LLMO, and NEO (Naver), with a finance-focused trust layer for source quality, freshness, fact/forecast separation, and citation readiness.

## Current phase

**V0.1 — Audit Engine**

The first release focuses on reproducible auditing before recommendation, content optimization, or automation features are added.

## Core principles

Accuracy → Primary Source → Freshness → Machine Readability → Citation → Ranking → CTR

## Upstream

This project is inspired by and will preserve attribution to `leopard627/fire-your-seo-agency` while developing a JoyLab-specific architecture for Korean search, AI citation, and finance/investment content quality.
